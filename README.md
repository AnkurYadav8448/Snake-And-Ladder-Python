# Snake and Ladder Game

A two-player Snake and Ladder game developed using Python and Tkinter.

## Features

- Interactive 10x10 game board
- Two-player gameplay
- Graphical dice
- Dice rolling animation
- Player movement animation
- Snake and ladder movement
- Turn management
- Winner announcement
- Restart game option

## Technologies Used

- Python
- Tkinter
- Random module

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

python main.py
